# 多益閱讀訓練室

多益閱讀訓練網站,有兩種運作模式,由 `js/cloud-config.js` 是否填值決定:

- **本機模式**(預設,config 留空):雙擊 `index.html` 就能用,不需伺服器;
  學生檔案與進度存在該裝置的瀏覽器 localStorage。
- **雲端模式**(填入 Supabase 金鑰):放上 GitHub Pages,學生用老師發放的帳號密碼登入,
  進度自動同步、換裝置可接續;老師帳號另有「教師後台」(admin.html)可總覽
  每位學生的檢測結果、各 Part 正確率與錯題。設定步驟見 **GITHUB上線指南.md**。

## 結構

```
index.html      首頁
diagnostic.html 程度檢測(28 題鑑別卷+報告)
reading.html    閱讀訓練(文章列表/閱讀器)
practice.html   題庫刷題(Part 5/6/7)
admin.html      教師後台(雲端模式+教師帳號限定)
css/style.css   全站樣式
js/             介面程式(profile.js=身分層、cloud.js=雲端同步、cloud-config.js=金鑰)
data/           題庫(由 tools/merge_data.py 產生,勿手改)
data/raw/       題庫原始 JSON(要改題目改這裡,改完重跑 merge)
img/            文章配圖(SVG)與 favicon
tools/merge_data.py      題庫合併+驗證腳本
tools/supabase_setup.sql 雲端資料庫初始化(貼進 Supabase SQL Editor)
GITHUB上線指南.md        上線與發帳號的完整步驟
```

## 學生檔案(非公開帳號)

- 進「程度檢測/閱讀訓練/題庫刷題」會先要求建立或選擇學生檔案(輸入名字即可)。
- 每位學生的進度、錯題、檢測報告各自獨立,存在該裝置瀏覽器的 localStorage。
- 右上角選單:切換學生、新增學生、**匯出進度**(下載 JSON,可傳給老師或帶到另一台電腦)、**匯入進度檔**、刪除檔案。
- 同一台電腦多位學生輪流上課沒問題;換瀏覽器或換電腦要靠匯出/匯入。

## 程度檢測

28 題(單句填空 20 題×12 考點+段落填空 1 篇+閱讀理解 1 篇),難度分基礎/中級/進階。
作答中不顯示對錯;交卷後產生報告:參考級距、各考點穩固/部分掌握/待加強、
逐題錯題分析(選錯的選項對應哪個迷思)、建議練習順序(可一鍵跳到對應題型)。
報告可列印或存 PDF。重新檢測不會動到刷題與閱讀進度。

## 常見維護

**改題目/加題目**:編輯 `data/raw/` 裡對應的 JSON,然後執行:

```
python tools/merge_data.py
```

腳本會驗證欄位、簡體字、標記對應,全過才會重新產生 `data/*.js`。

**換文章配圖**(兩種方式擇一):
1. 直接把 `img/art-1a.svg` 等同名檔換成你的 SVG。
2. 想用照片:把 jpg/png 放進 `img/`,在 `data/raw/articles_b*.json` 該篇文章加一個欄位
   `"image": "img/我的圖.jpg"`,重跑 merge 即可(有 image 欄位就優先用它)。

**清除某個學生的進度**:網站內各頁都有「清除紀錄」按鈕;或瀏覽器開發者工具清 localStorage(鍵以 `tr_` 開頭)。

## 給學生的使用方式

1. 閱讀訓練:文章分初級/中級/中高級/高級。虛線單字可點 → 原位置變空格、填空小卡浮在字上方 →
   提示分兩層(英文提示 → 中文意思),自己拼進去才算完成,拼對亮黃色;之後再點直接看中文。
   「對照翻譯」可切英中兩欄對照。
2. 題庫刷題:「隨機練習」選題型與題數,系統優先抽沒做過的題目,逐題即時解析;
   答錯自動進「錯題本」,重新答對就移出。
