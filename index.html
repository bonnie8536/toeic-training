單字是這樣練的

文章裡有虛線的單字都可以點。不是點了就給答案——要自己想、自己拼出來,才記得住。

1 點一下,單字變成空格 忘記這個字?點它,原位置變成空格,填空小卡會浮在字的上方。
The company will implement a new policy.
2 提示分兩層,自己拼出來 先看英英釋義;還是不會,再看中文意思——但單字要自己拼進去才算完成。
HINT to start using a plan or system officially
中文意思 實施;執行
3 填過的字,再點就給翻譯 完成過的單字會標黃。之後再點,直接顯示中文意思和原形,當成自己的單字卡。
The company will implement a new policy.
